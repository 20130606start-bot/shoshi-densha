プライバシーポリシー

shoshi-gas（司法書士試験の学習アプリ）

このアプリは、作った本人が、自分の勉強のためだけに使っている個人用のアプリです。 ほかの方に配布しておらず、利用者は本人1人です。

1. 集めている情報

このアプリは、利用者ご本人のGoogleアカウントの中にあるデータだけを扱います。 外部のサーバーに送ることはありません。

使う権限何のために使うか
Googleスプレッドシート問題文・解説と、解いた記録・自分で書いた一文を読み書きするため
Googleドライブ学習用の資料（図解など）を置き、アプリから開くため
メールアドレス・基本的なプロフィールアプリを開いた人が本人かどうかを確かめるため
外部への通信条文の参照など、学習に必要な情報を取得するため

2. 第三者への提供

行いません。取得した情報を、第三者に売ったり、渡したり、広告に使ったりすることはありません。 広告そのものを表示していません。

3. 保存される場所

  • 学習の記録 … 利用者ご本人のGoogleスプレッドシート
  • 通信が無いときに一時的に持つ分 … 利用者ご本人の端末のブラウザの中（localStorage）

いずれもご本人の管理下にあります。開発者が別の場所に控えを取ることはありません。

4. 削除のしかた

  • Googleアカウントの サードパーティ接続 から、このアプリのアクセス権をいつでも取り消せます
  • 記録そのものは、ご本人のスプレッドシートを削除すれば消えます
  • 端末に残る分は、ブラウザの閲覧データを消せば消えます

5. Googleユーザーデータの取り扱い

このアプリがGoogle APIから受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。

受け取った情報は上の表に書いた目的のためだけに使い、それ以外の目的には使いません。
