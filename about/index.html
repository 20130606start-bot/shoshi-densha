shoshi-gas

司法書士試験の勉強のために、個人が自分用に作って、自分だけで使っている学習アプリです。

何をするアプリか

司法書士試験の過去問を「肢（し）」という小さな単位に分けて、1問ずつ解き、 どこまで理解できたかを記録していくための道具です。

  • 過去問の肢を1つずつ出して、◯か✕かで答える
  • なぜその答えになるのかを、自分の言葉で1文だけ書き残す
  • 解いた記録・手応えを貯めて、次に何を復習すればよいかを出す
  • 電車の中などで、通信が無くても解けるようにする

だれが使っているか

作った本人 1人だけです。ほかの方に配ったり、登録を募ったりしていません。 広告もありません。料金もありません。

どこで動いているか

  • アプリ本体 … Google Apps Script（本人のGoogleアカウントの中）
  • 記録の置き場 … 本人のGoogleスプレッドシート
  • 通信が無くても使う部分 … GitHub Pages（このページと同じ場所）
